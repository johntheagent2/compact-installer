# Essential App Installer

This project helps a user reinstall their essential applications after reinstalling Windows.

## Language

**App catalog**:
The list of applications the installer offers for selection.
_Avoid_: Download list

**App selection**:
The applications the user has chosen to install from the app catalog.
_Avoid_: Download queue

**Destination disk**:
The disk the user chooses for new application installations that support a custom location. Choosing C: means using each app's default location.

**App default location**:
The installation directory chosen by an application's own installer when the user does not supply a custom destination.
